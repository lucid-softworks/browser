# Bundled page font

`Inter-Regular.ttf` is the unmodified regular face bundled by Rune at revision
`1dba3423fd1f1904553422e7814700f817abe8af`, from
[`crates/rune/assets`](https://github.com/anomalyco/rune/tree/1dba3423fd1f1904553422e7814700f817abe8af/crates/rune/assets).
Inter is copyright The Inter Project Authors and distributed under the SIL Open
Font License 1.1; see `Inter-LICENSE.txt`.

The desktop shell supplies these bytes to the browser engine so page text remains
available on systems with nonstandard font paths or no installed default font.
Installed fallback fonts are still used for glyphs absent from Inter.
